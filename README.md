# Remote Play

Remote Play lets you save and connect to your Windows PCs through Sunshine and Moonlight.

[Download Remote Play Setup for Windows](https://github.com/Demoncooki3/remote-play-downloads/releases/latest/download/Remote-Play-Setup.exe)

Run the same setup file on both Windows 10 or 11 PCs. Setup needs internet access and Windows Package Manager (App Installer). Windows may ask for administrator approval.

1. On the gaming PC, choose **Gaming PC** to install Sunshine. Open Sunshine, create your login, and confirm the **Desktop** app is listed. Keep the gaming PC awake with Sunshine running.
2. On the PC you connect from, choose **PC I connect from**. Setup installs Moonlight and adds Remote Play to the Start menu.
3. To connect away from home, use an approved private network. If you select the optional Tailscale install, sign in to the same private network on both PCs and use the gaming PC's Tailscale IP address.
4. In Remote Play, select **Add PC**, enter the gaming PC's address, and select **Save PC**. Select **Pair PC** and enter the PIN in Sunshine on the gaming PC. Then select **Connect**.
